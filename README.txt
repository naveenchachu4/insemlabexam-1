TASK MANAGEMENT SYSTEM
======================

Project Name:
Task Management System


HOW TO RUN
==========

1. Open the project folder in VS Code.

2. Make sure these files are present:

   index.html
   style.css
   script.js
   README.txt

3. Open index.html.

4. Right-click index.html.

5. Select "Open with Live Server".


PROJECT FEATURES
================

1. Home Page

2. Task Management System title

3. Simple pictures and icons

4. Create Tasks

5. Track Progress

6. Set Priority

7. Due Dates

8. Add Task

9. Delete Task

10. Change Task Status

11. Task Progress Visualization

12. Animated left-to-right task movement

13. Task Status Donut Visualization

14. Local Storage
